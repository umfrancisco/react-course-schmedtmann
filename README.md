# Master modern React from beginner to advanced! Next.js, Context API, React Query, Redux, Tailwind, advanced patterns (Udemy Course)

A collection of exercises, practice applications, and projects developed while following a Udemy course on **React, modern frontend development, and Next.js** from Jonas Schmedtmann.

This repository documents my learning journey through the React ecosystem, covering component-based architecture, hooks, state management, routing, performance optimization, styling, and full-stack application development.

The goal is to strengthen my understanding of React and its surrounding ecosystem by applying modern development practices through hands-on projects.

## Topics Covered

### React Fundamentals
- JSX, components, props, and event handling.
- State management and controlled forms.
- Component composition and reusable UI elements.
- Thinking in React and designing component hierarchies.
- Rules of Hooks and custom hooks.

### Hooks and State Management
- `useState`, `useEffect`, `useRef`, and `useReducer`.
- Context API for shared state.
- Local state vs. global state.
- UI state vs. remote server state.
- Redux and Redux Toolkit.
- Redux Thunks and asynchronous operations.
- React Query for server-state management.

### Routing and Data Fetching
- Vite and Single-Page Applications (SPAs).
- React Router and client-side navigation.
- URL parameters and query strings.
- Route loaders and actions.
- Data fetching and synchronization.

### Styling and UI Development
- CSS Modules.
- Tailwind CSS.
- Styled Components.
- Reusable and composable components.
- Dark mode and responsive interfaces.

### Advanced React Concepts
- Component lifecycle and effect synchronization.
- Performance optimization with `memo`, `useMemo`, and `useCallback`.
- Code splitting and Suspense.
- Higher-Order Components and render props.
- Compound component patterns.
- Virtual DOM, reconciliation, and React rendering.
- Portals, refs, event handling, and state batching.

### Full-Stack Development
- Supabase as a backend service.
- Database integration and API consumption.
- Authentication and authorization.
- Sorting, filtering, and pagination.
- Dashboards and data visualization.

### Next.js
- Next.js App Router.
- React Server Components and Client Components.
- Server Actions.
- Server-side rendering and static rendering.
- Data loading, caching, and streaming.
- Server/client state management.
- Authentication and modern React form patterns.
- Image and font optimization.

## Learning Objectives

Through the exercises and projects in this repository, I aim to:

- Develop a solid understanding of React and its rendering model.
- Build reusable, maintainable, and composable components.
- Manage application state effectively using React hooks and external libraries.
- Develop single-page applications with client-side routing.
- Integrate frontend applications with APIs and backend services.
- Apply modern styling approaches to create responsive user interfaces.
- Understand performance optimization techniques and advanced React patterns.
- Explore full-stack development with Next.js and Supabase.
- Improve my ability to build production-oriented web applications using the React ecosystem.
